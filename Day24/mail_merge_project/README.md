**Developer:** Daniel Alejandro Castillo Martín

---

This folder contains all the scripts and resources created for the Mail Merge Project, part of **Day 24** of _Udemy’s 100 Days of Code: The Complete Python Pro Bootcamp_, developed and taught by Dr. Angela Yu.

## About this project

- The program can be executed by running the `main.py` file, which performs a mail merge operation using template letters and a list of names.
- The project reads a template letter and a list of recipient names, then generates personalized letters for each recipient and saves them in the `Output` folder.
  - `Input/`: Contains the template letter and the list of names to use for the mail merge.
  - `Output/`: The folder where the personalized letters are saved after the merge operation.
  - `src/`: Contains the main logic for reading files, processing the mail merge, and writing the output letters.
