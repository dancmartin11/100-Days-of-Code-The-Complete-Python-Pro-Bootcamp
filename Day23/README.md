# Turtle Crossing Project

**Developer:** Daniel Alejandro Castillo Martín

---

This folder contains all the scripts and resources created for the Turtle Crossing Game Project, part of **Day 23** of _Udemy’s 100 Days of Code: The Complete Python Pro Bootcamp_, developed and taught by Dr. Angela Yu.

## About this project

- This project is a Turtle Crossing game inspired by the classic Frogger arcade game, implemented using Python's Turtle module. Run the game by executing the `main.py` file in the Day23 folder.
- The player controls a turtle that must cross a road filled with moving cars to reach the finish line at the top of the screen.
- Each time the player successfully crosses, the level increases and the cars move faster, making the game progressively more challenging.
- Controls:
  - Move the turtle up: Use the Up arrow key.
- The game logic and main loop are in `main.py`, while the core components are organized in the `src` folder:
  - `src/player.py`: Contains the Player class for the turtle's movement and position logic.
  - `src/car_manager.py`: Contains the CarManager class for generating, moving, and managing cars.
  - `src/scoreboard.py`: Contains the Scoreboard class for displaying and updating the current level and game over message.
