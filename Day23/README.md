This folder contains all the scripts and resources created for the Pong Game Project, part of **Day 23** of _Udemy’s 100 Days of Code: The Complete Python Pro Bootcamp_, developed and taught by Dr. Angela Yu.

## About this project

- This project is a classic Pong game implemented using Python's Turtle module. Run the game by executing the `main.py` file in the Day23 folder.
- The game features two paddles (left and right), a bouncing ball, and a scoreboard to keep track of each player's points.
- Controls:
  - Right paddle: Use the Up and Down arrow keys.
  - Left paddle: Use the 'w' (up) and 's' (down) keys.
- The game logic and main loop are in `main.py`, while the core components are organized in the `src` folder:
  - `src/paddle.py`: Contains the Paddle class for paddle movement and control.
  - `src/ball.py`: Contains the Ball class for ball movement and collision logic.
  - `src/scoreboard.py`: Contains the Scoreboard class for displaying and updating scores.
