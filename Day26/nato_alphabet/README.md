**Developer:** Daniel Alejandro Castillo Martín

---

This folder contains all the scripts and resources created for the NATO Alphabet Project, part of **Day 26** of _Udemy’s 100 Days of Code: The Complete Python Pro Bootcamp_, developed and taught by Dr. Angela Yu.

## About this project

- The program can be executed by running the `main.py` file, which converts user-input words into their corresponding NATO phonetic alphabet code words.
- The project reads the official NATO phonetic alphabet from a CSV file and uses it to translate any word provided by the user.
  - `data/nato_phonetic_alphabet.csv`: Contains the mapping of letters to their NATO phonetic code words.
  - `main.py`: Contains the main logic for reading the CSV, processing user input, and displaying the phonetic translation.
