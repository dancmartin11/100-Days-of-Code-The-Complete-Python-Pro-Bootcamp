**Developer:** Daniel Alejandro Castillo Martín

This folder contains all the scripts and resources created for the Etch a Sketch Mini-Project, part of **Day 19** of _Udemy’s 100 Days of Code: The Complete Python Pro Bootcamp_, developed and taught by Dr. Angela Yu.

## About this project

- This program simulates the behavior of an *Etch a Sketch* board.
- The program can be executed by running the `main.py` file, which calls the main program functions, using resources located in the `src/Commands.py` file.
- When running the main file, you can start drawing in the board by interacting with the following commands:
  - **W**: *Move forward.*
  - **S**: *Move back.*
  - **A**: *Turn left.*
  - **D**: *Turn right.*
  - **C**: *Clear the screen and move the pen back to the starting position.*
  - **R**: *Change the pen's color into a random color.*
