This folder contains all the scripts and resources created for the Turtle Race Mini-Project, part of **Day 19** of _Udemy’s 100 Days of Code: The Complete Python Pro Bootcamp_, developed and taught by Dr. Angela Yu.

## About this project

- This program generates a turtle race, where the user can bet on which turtle is going to win by typing their selected turtle's color.
- Turbo Turtle's colors:
  - *Blue*
  - *Green*
  - *Orange*
  - *Purple*
  - *Red*
  - *Yellow*

- The program can be executed by running the `main.py` file, which will automatically open the screen and ask for a bet.
- When running the main file, you can start drawing in the board by interacting with the following commands:
  - **W**: *Move forward.*
  - **S**: *Move back.*
  - **A**: *Turn left.*
  - **D**: *Turn right.*
  - **C**: *Clear the screen and move the pen back to the starting position.*
  - **R**: *Change the pen's color into a random color.*
