# Damien Hirst Painting Project

**Developer:** Daniel Alejandro Castillo Martín

---

This folder contains all the scripts and resources created for the Damien Hirst Painting Project, part of **Day 18** of _Udemy’s 100 Days of Code: The Complete Python Pro Bootcamp_, developed and taught by Dr. Angela Yu.

## About this project

- The program can be executed by running the `main.py` file, which calls the main program function located in the `src/turtle_art.py` file.
- The `turtle_art.py` file contains the main function for generating an artwork inspired by Damien Hirst's paintings, referenced in `docs/damien_hirst_painting.png`.
  - The colors were extracted from the same image using the module located in `utils/image_utils.py`, and a random color is selected each time the Turtle object draws a new dot.
