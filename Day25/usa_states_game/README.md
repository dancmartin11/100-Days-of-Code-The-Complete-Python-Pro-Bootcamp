# USA States Game Project

**Developer:** Daniel Alejandro Castillo Martín

---

This folder contains all the scripts and resources created for the USA States Game Project, part of **Day 25** of _Udemy’s 100 Days of Code: The Complete Python Pro Bootcamp_, developed and taught by Dr. Angela Yu.

## About this project

- The program can be executed by running the `main.py` file, which launches an interactive game where you guess the names of all 50 U.S. states.
- The game displays a blank map of the United States and prompts you to enter state names. Correct guesses are marked on the map, and your progress is tracked throughout the game.
  - `data/`: Contains the CSV file with the list of all U.S. states and their coordinates for placement on the map.
  - `images/`: Contains the map image used for the game display.
  - `src/`: Contains the main logic for handling user input, checking guesses, and updating the map.
